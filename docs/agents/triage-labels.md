# 分类标签

工程技能使用五个标准分类角色。此文件将这些角色映射到本仓库问题追踪器中的实际标签。

| 技能中的标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给自动代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个分类角色时，使用表格中对应的实际标签。
